# Exact two-player input isolation — 2026-07-22

## Result

PASS using `tests/splitscreen/cfg/input_isolation_2p.cfg` with P1 assigned
keyboard/mouse and P2 assigned controller1.

UI assertions proved:

- Controller1 changed P2 from `reborn/default` to `reborn_new/default` while P1
  remained `kyle/default`.
- Keyboard changed P1 from `kyle/default` to `lando/default` while P2 remained
  `reborn_new/default`.
- An extreme mouse delta `(10000,10000)` was clamped to `(600,200)`, the
  upper-right legal cursor origin in P1's 640x240 viewport. Mouse owner and UI
  target both reported P1, and P2's selection remained unchanged.

Gameplay command assertions proved:

- Keyboard forward generated P1 `forwardmove=127`; P2 remained zero.
- Mouse motion left P2 movement/buttons and command angles at zero.
- Controller1 forward generated P2 `forwardmove=127`; P1 movement remained
  zero.
- Controller1 button 0 generated P2 `buttons=1`; P1 buttons remained zero.
- Releasing controller1 returned P2's command to zero.
