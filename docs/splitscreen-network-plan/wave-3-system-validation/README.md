# Wave 3: Full-System Validation

Begin after Waves 1 and 2 are merged and stable. Tickets are independent test
tracks; each may file and fix defects only in its assigned area. Cross-area bugs
must be documented for integration rather than patched concurrently.

## Tickets

- [W3-01: Local hosting matrix](W3-01-local-host-matrix.md)
- [W3-02: Vanilla internet compatibility matrix](W3-02-internet-compatibility.md)
- [W3-03: Controller and visual workflow audit](W3-03-controller-visual-audit.md)
- [W3-04: Lifecycle and fault stress](W3-04-lifecycle-fault-stress.md)

## Exit gate

All supported player counts, game types, menu paths, input assignments, server
transitions, and representative network failures pass with inspected artifacts.
