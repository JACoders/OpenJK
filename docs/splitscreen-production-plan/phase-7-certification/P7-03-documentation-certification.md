# P7-03: Certify Documentation Workflows

## Objective

Prove that player, operator, contributor, and troubleshooting instructions match
the frozen candidate.

## Primary ownership

`artifacts/certification/documentation` and documentation test homepaths only.
Do not edit docs, source, packages, or other reports.

## Work

1. Replay every quick-start, device, profile, console, host, and join procedure.
2. Replay server capacity, remote fifth-player, vanilla, and recovery procedures.
3. Verify commands, paths, screenshots, defaults, and known limitations.
4. Record pass/fail evidence by document section.

## Acceptance criteria

- Every documented procedure succeeds exactly as written.
- Screenshots match the candidate and have human visual review.
- No unsupported completion or compatibility claim remains.
- The report identifies document and executable hashes.
