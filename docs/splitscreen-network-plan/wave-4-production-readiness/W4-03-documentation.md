# W4-03: User and Operator Documentation

## Objective

Document the final workflows and limitations without requiring developer CVARs.

## Work

1. Document local party setup, stock local hosting, LAN joining, internet joining,
   passwords, controller assignment, profiles, consoles, and virtual keyboards.
2. Document host firewall/NAT/port considerations and remote slot capacity.
3. Explain that all local players share one server and cannot join separate games.
4. Document vanilla compatibility and known per-IP/mod limitations.
5. Add troubleshooting based on actual error messages and recovery actions.
6. Add developer architecture and QA instructions for future contributors.

## Acceptance criteria

- A new user can host four local plus one remote player from the UI alone.
- A new user can join a vanilla server with a local party from the UI alone.
- Instructions match the packaged ARM64 build and contain no stale screenshots.
- Developer commands are clearly separated from normal user workflows.

## Deliverables

- User guide, host/network guide, troubleshooting guide, and architecture notes.
